# CAD Files Instructions
---
###This documentation provides details on accessing the relevant CAD files for the project
---
## Step 1:
- Access the link: https://drive.google.com/file/d/1An3hWztXCAx--te5ntcp9dpjbVQCHd8c/view?usp=drive_link

## Step 2: 
- Download the file named "CAD Parts.zip" and extract all files

## Step 3:
- To access the Full CAD of the robot "**CAD Parts > Solidworks Part > Full CAD Base**" and click the "Full CAD Base" part file
- The base parts of the standard Turtlebot are in the "Parts" file while any modified parts are found in the "Full CAD Base" file
